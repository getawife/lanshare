# Security Policy

Lanshare moves files between devices on a local network. This document describes the threat model, the security properties the code aims to provide, and how to report problems.

## Reporting a vulnerability

Please do not open a public issue for security-sensitive reports. Click [here](https://github.com/getawife/lanshare/security/advisories/new)

- A description of the issue.
- Steps to reproduce, or a proof of concept.
- The Lanshare version (visible in Settings under "About").
- Your operating system and version.
- Any relevant network setup (same LAN, wired, Wi-Fi, VPN, etc.).

If the report is valid, a fix will be developed privately and released before public disclosure.

For lower-severity issues that do not expose user data or allow remote code execution, feel free to open a regular GitHub issue. Use your judgement.

## Supported versions

Only the latest release receives security updates. If you are running an older version, update first, then re-test the issue. The updater handles this automatically on Windows, macOS ARM64, and Linux x64.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |
